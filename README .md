
# Point‑to‑Point Single‑Area OSPFv2 Configuration

This repository contains router configurations for a Cisco Packet Tracer lab focusing on:
- OSPFv2 single‑area routing
- Router IDs
- Wildcard masks
- Quad‑zero network statements
- Interface‑level OSPF activation
- Passive interfaces

## Routers & Networks
- **R1**: Uses wildcard‑mask network statements
- **R2**: Uses quad‑zero (0.0.0.0) network statements
- **R3**: Uses interface‑level OSPF configuration

## Files Included
- `R1.txt` – Full R1 OSPF config
- `R2.txt` – Full R2 OSPF config
- `R3.txt` – Full R3 OSPF config
